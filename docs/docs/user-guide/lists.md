# Lists & Collections

Lists allow you to organize, collect, and share media with others.

## List Types

### User Lists

Lists created by you. You have full control:

- Change name, description, and visibility
- Add and remove any media
- Private (only for you) or public (visible to everyone)
- Delete when no longer needed

### System Lists

Lists automatically created by the system:

- Created by admins via "Import Trending"
- Contain e.g. current trending movies from TMDB or popular games from IGDB
- Automatically updated
- Only editable by admins

## Creating a List

### From the Side Menu

1. Open the side menu
2. Under **My Lists** click the **+** icon
3. Enter a name
4. The list will be created as a private user list
5. You will be automatically redirected to the new list

### Via the List Dialog

When you want to add a medium to a list and don't have a suitable one yet, you can create a new one directly.

## Adding Media to Lists

1. Open the detail page of a movie, series, or game
2. Click **Add to List** (list icon)
3. A dialog shows all your lists
4. Select the desired list
5. The medium is added

## Viewing a List

Click on a list in the side menu or navigate to `/lists/{list-id}`. The list page shows:

- **List Name** and **Description**
- All contained media as a poster grid
- Actions for editing and managing

## Editing a List

1. Open your list
2. Click **Edit**
3. A dialog opens with:
    - **Name**: Change list name
    - **Description**: Change description text
    - **Visibility**: Switch between private and public
4. Click **Save**

## List Interactions

Public lists offer social features:

- **Like**: Show that you like a list (heart icon)
- **Follow**: Follow a list for updates
- **Bookmark**: Save a list for later access

!!! info "Note"
    You can only like and follow public lists of other users - not your own.

## Visibility

| Visibility | Who can see it? | Interactions possible? |
|-------------|---------------------|----------------------|
| **Private** | Only you | No |
| **Public** | All logged-in users | Yes (Like, Follow, Bookmark) |

## List Ideas

- **Watchlist**: Movies and series you still want to watch
- **Favorite Genre**: "Best Sci-Fi Movies", "Horror Classics"
- **Theme Night**: "Movie Night Selection", "Sunday Series"
- **Game Collection**: "Backlog", "Completed", "Currently Playing"
