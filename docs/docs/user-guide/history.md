# Playback History

The playback history shows everything you have watched - with progress indicators and the ability to continue exactly where you left off.

## Opening the History

Open the history via:

- **Side menu** -> **History**
- Or navigate directly to `/history`

## Overview

The history is displayed as a table with the following columns:

| Column | Description |
|--------|-------------|
| **Title** | Movie title or series name with episode info (e.g. "Breaking Bad - S02E05: Breakage"), with thumbnail |
| **Progress** | Progress bar with percentage and time display, or "Completed" badge |
| **Last watched** | Relative time display (e.g. "3 hours ago", "yesterday", "5 days ago") |
| **Actions** | Continue watching/Watch again and Delete |

### Media Type Detection

Each entry shows a colored badge:

- **Movie**: Blue-grey badge with movie icon
- **Episode**: Purple badge with TV icon

## Continue Watching

Click the **Play button** next to an entry:

- **Not completed**: "Continue watching" - resumes where you left off
- **Completed**: "Watch again" - starts from the beginning

## Deleting an Entry

1. Click the **Trash icon** next to an entry
2. Confirm the deletion in the dialog
3. The entry is removed from your history

## Continue Watching on the Home Page

If the admin has configured a **Continue Watching section** in the page layout, your unfinished media appear directly on the home page as a horizontal carousel with progress bars.
